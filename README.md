# Python Quiz App 🐍

A simple interactive quiz application built with Python and CustomTkinter.

## Features

- Multiple-choice questions about Python.
- Radio buttons for selecting answers.
- Instant feedback after checking answers.
- Separate results for each question.
- Dark mode interface.

## Quiz Topics

1. Immutable Python data types.
2. Python data types that do not allow duplicate elements.

## Requirements

- Python 3.10 or newer
- CustomTkinter

## Installation

Install the required library:

```bash
pip install customtkinter
```

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run the application:

```bash
python main.py
```
